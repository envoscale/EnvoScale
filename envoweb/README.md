# EnvoWeb: websites

Routes, pages and a web server in EnvoL, and static sites built from the same code.
Pages are written in Markdown or built from templates drawn with EnvoR's theme.

<p align="center"><img src="https://raw.githubusercontent.com/envoscale/.github/main/profile/assets/site-home.png" alt="A website generated by an EnvoL program" width="100%"></p>

```cs
use envoweb as web;
use envo.http;

http.Response Home(in http.Request req, in web.Params ps) => http.Response.Html(200, "<h1>Hello</h1>");

web.App app = web.App.New();
app.Get("/", new web.Page { Fn = Home });
web.Serve(ref app, "127.0.0.1", 8080);
```

| Module | |
|---|---|
| [`envoweb`](https://github.com/envoscale/EnvoWeb/tree/main/web) | Routes, pages, the server, static builds |
| [`envoweb.templates`](https://github.com/envoscale/EnvoWeb/tree/main/web/templates) | Page layouts |
| [`envoweb.markdown`](https://github.com/envoscale/EnvoWeb/tree/main/markdown) | Markdown to HTML |
